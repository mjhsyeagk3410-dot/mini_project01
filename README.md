# 미니 프로젝트 발제 — 쇼핑몰 장바구니 & 할인 쿠폰
## AX3기 서재홍
[연결된 레포 주소](https://github.com/mjhsyeagk3410-dot/mini_project01.git)
파일 설명
```md
REAEME.md : 프로젝트를 어떻게 만들지에 대해서
cheatkey.py : AI의 힘을 빌려서 미니 프로젝트를 푼 결과물. 아래 README.md 내용은 cheatkey.py 내용 기반으로 만들어짐
main.py : AI없이 순수 개발 실력 (미완성 제출)
```

### 결제 시스템 프로그램 소개
```md
파이썬 객체지향 프로그래밍(OOP)개념과 클래스 상속, 캡슐화를 활용해 터미널 환경에서 실행되는 온라인 쇼핑몰 장바구니 및 결제 프로그램입니다. 
```

### 구현한 기능 (Features)
```md
1. 상품 관리 및 자동 번호 부여(Product 클래스)
2. 할인 쿠폰 상속 및 다형성 구조(Coupon 부모/자식 클래스)
3. 장바구니 및 결제 금액 계산(Cart 및 ShoppingMall 클래스)
```

### 프로그램 구조
```md
사용된 클래스: 6개 
    - Product
    - Discount(쿠폰: 부모)
    - RateDiscount(쿠폰: 자식1)
    - FixedDiscount(쿠폰: 자식2)
    - Cart
    - ShoppingMall
상속받은 자식 클래스:2개 
    - RateDiscount(쿠폰: 자식1)
    - FixedDiscount(쿠폰: 자식2)
```

### 실행 방법
```md
1. 요구 사양
- Python 3.15 버전
- 별도 외부 라이브러리 설치 없이 파이썬 표준 라이브러리만으로 실행됩니다

2. 파일 실행하기
- 터미널 또는 vs code 통합 터미널을 엽니다 
- 프로젝트 파일이 위치한 경로로 이동한뒤 아래 명령어를 입력하여 실행합니다
```
```sh
python main.py
```

3. 프로그램 조작법   
**프로그램이 실행되면 터미널 화면에 아래와 같은 메뉴가 출력됩니다. 번호를 입력하면 쇼핑이 가능합니다**
```md
1. 상품목록: 등록된 전체 상품의 번호, 가격, 남은 재고를 확인
2. 담기: 상품 번호와 수량을 입력해 장바구니에 상품을 추가
3. 빼기: 장바구니에서 특정 상품을 제거
4. 장바구니: 현재 담긴 상품 목록과 상품 합계, 할인금액, 배송비, 최종 결제 금액을 미리 확인
5. 쿠폰: 사용 가능한 할인 쿠폰 목록을 확인하고 적용
6. 결제: 최종 영수증을 출력하고 재고를 차감한 뒤 장바구니를 초기화    
q. 프로그램을 종료
```
